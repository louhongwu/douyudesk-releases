# 斗鱼监控台 DouyuDesk（发布版下载）

斗鱼/虎牙多房间桌面监控工具。无广告、不登录账号、纯拉流播放。

## 下载

在右侧 **Releases** 页面下载 `DouyuDesk-v1.0.2.zip`（压缩包，Windows 自带解压；解压出 `DouyuDesk.exe` 双击运行，免安装，需要 Windows 10/11 x64）。

> **SmartScreen 提示说明**：程序未做代码签名，首次运行如遇 Windows 提示"已保护你的电脑"，点 **"更多信息" → "仍要运行"** 即可——属未签名程序的正常现象，安全无风险。

> **国内直连**（Gitee，无需梯子，7z 分卷需 7-Zip 解压）：https://gitee.com/louhongwu/douyudesk-releases/releases

## 功能

- 单个窗口最多同时监控 **16 个**斗鱼/虎牙直播间
- **飘屏弹幕**：等级多色 / 按昵称彩色模式，字号/速度/位置/透明度可调，支持单房间独立设置
- **数据面板**：今日活跃、已播时长、弹幕人数、礼物价值、贵宾数、实时帧率（仅斗鱼）
- **轮播/录播识别**：小窗徽章 + 列表标签标注
- **全屏局部放大**：滚轮缩放、中键拖动手平移
- 房间列表按开播状态+热度排序、隐藏未开播
- 贵宾暴涨提醒（爆宾）、观看休息提醒
- 未开播自动检测、断流自动重连、流地址自动续期
- 最小化到系统托盘、深色界面
