# 斗鱼监控台 DouyuDesk（发布版下载）

斗鱼 / 虎牙 / B站 / 抖音 多房间桌面监控工具。无广告、纯本地播放；B站/斗鱼发弹幕需对应平台扫码登录。

## 下载

在右侧 **Releases** 页面下载最新版 `DouyuDesk_vX.Y.Z.exe`（单文件，免安装，解压后直接运行；需要 Windows 10/11 x64）。

> **SmartScreen 提示说明**：程序未做代码签名，首次运行如遇 Windows 提示"已保护你的电脑"，点 **"更多信息" → "仍要运行"** 即可——属未签名程序的正常提示。

## 功能

- 单窗口最多同时监控 **16 路**直播间（斗鱼/虎牙/B站/抖音，每平台上限 30 房间）
- **发弹幕**：B站（直连接口）、斗鱼（直连弹幕服务器）——💬 按钮呼出弹幕小窗，回车发送，画面浮动提示结果，自动验证上屏
- **扫码登录**：B站（原画/高清权限 + 发弹幕）、斗鱼（发弹幕），登录界面为官方网页，登录态本机加密保存
- **自己发的弹幕飘屏七彩渐变** +「[我]」标识
- **飘屏弹幕**：等级多色 / 按昵称彩色 / 七彩自己弹幕，字号/速度/位置/透明度可调，支持单房间独立设置；**等级屏蔽**（斗鱼6级/B站3级以下过滤机器人弹幕）
- **画质标签**：每路显示当前档位（B站=原画/超清；斗鱼=原画/超清/高清/流畅；抖音=原画/高清/标清；虎牙=原画）
- **数据面板**：今日活跃、已播时长、弹幕人数、礼物价值、贵宾数（仅斗鱼）、真实在线人数（B站）
- 房间列表按平台分组 + 开播状态/热度排序、隐藏未开播
- 贵宾暴涨提醒（爆宾）、观看休息提醒
- 未开播自动检测、断流自动重连、流地址自动续期（B站 HLS 断流秒级恢复）
- 双击画面/按钮全屏、最小化到系统托盘、深色界面
