## 功能

- 四平台直播监控：斗鱼 / 虎牙 / B站 / 抖音
- 单个窗口最多同时监控 **16 个**直播间，支持多平台混合监控
- **飘屏弹幕**：等级多色 / 按昵称彩色模式，字号/速度/位置/透明度可调，支持单房间独立设置
- **抖音/B站弹幕表情图片**显示（内置 214 个抖音表情）
- **数据面板**：今日活跃、已播时长、弹幕人数、礼物价值、贵宾数、实时帧率
- **观众人数显示**：B站真实在线人数、抖音在线观众数
- 轮播/录播识别（小窗徽章 + 列表标签标注）
- 全网模式：粘贴直播间链接自动识别平台；也支持斗鱼/虎牙/B站/抖音前缀
- 房间列表按平台分组 + 按开播状态/热度排序、隐藏未开播
- 全屏局部放大（滚轮缩放、中键拖动手平移）
- 未开播自动检测、断流自动重连、流地址自动续期
- 最小化到系统托盘、深色界面
