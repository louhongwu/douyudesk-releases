# 多平台直播监控 DouyuDesk（发布版下载）

斗鱼 / 虎牙 / B站 / 抖音 多房间桌面监控工具。无广告、纯本地播放；B站/斗鱼/虎牙发弹幕需对应平台扫码登录。

## 下载

在右侧 **Releases** 页面下载最新版 `DouyuDesk_vX.Y.Z.exe`（单文件，免安装；需要 Windows 10/11 x64）。

## 功能

- 单窗口最多同时监控 **16 路**直播间（斗鱼/虎牙/B站/抖音，每平台上限 30 房间）
- **发弹幕**：B站、斗鱼、虎牙——💬 弹幕小窗，回车发送，画面浮动提示，自动验证上屏
- **扫码登录**：B站、斗鱼、虎牙（发弹幕/登录态），官方网页登录，登录态本机加密保存
- **自己弹幕飘屏七彩渐变** +「[我]」标识
- **飘屏弹幕**：多色/按昵称彩色/七彩，可调字号速度位置透明度；**等级屏蔽**（斗鱼6级/B站3级）
- **画质标签**：每路显示当前档位
- 房间列表按平台分组+开播状态排序；贵宾暴涨提醒；断流自动重连（B站 HLS 秒级恢复）
- 双击全屏、托盘最小化、深色界面
